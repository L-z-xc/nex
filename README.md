# nex (dsh-purge 1.1.92)

本仓库根目录为可安装的 DSH 插件包 dsh-purge@1.1.92（含 dsh.bundle / cordis.patch.yml）。

## 安装（推荐）
- DSH CLI：dsh plugin add "https://raw.githubusercontent.com/L-z-xc/nex/main/dsh-purge-1.1.92.tgz"
- 或下载 [dsh-purge-1.1.92.tgz](./dsh-purge-1.1.92.tgz) 后在 DSH 插件/扩展管理中选择本地文件安装。
- 安装后重启 DSH 生效。

## npm 包
根目录可直接 
pm pack 生成 dsh-purge-1.1.92.tgz。
